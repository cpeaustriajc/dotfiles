# Review loop

Step 9 of SKILL.md. Look the way the user will: the real page or file, desktop and phone width,
full size and zoomed.

1. Render the picture the way it ships (a browser for a web page, the exported file otherwise) and
   save the full frame at desktop and phone width.
2. Whole frame first: tradition, value plan, space.
3. Crop every element at 2×. Check each crop against its reference and the checklist below.
4. Fix, render again, compare with the last render. Keep before/after images and the steps that
   made them for the commit message.

Checklist: proportion (every reach works); pose; grounding; depth order along every mover's path;
space (no empty gap between scales); one light; tradition (no clip-art part); structure at zoom
(each hero crop shows built structure and at least three value steps); medium (no smeared or evenly
spread texture); states (every era, time, viewport, in-between frames); accuracy (proxies and
UNVERIFIED named).
