# Plain prose

Read before you publish a page (SKILL.md step 5). A check cannot match these, so read for them and
rewrite each one.

Rules 26-33 in `plugins/engineering/skills/blast-radius/references/ai-tells.md` (abstract metaphor
nouns, feelings instead of facts, dense sentences, passive voice, adverbs, plain words, mannered
prose, over-compression) apply to every page. For the rest, Wikipedia's "Signs of AI writing"
(https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing).

Two page-specific rules:

- **Real names.** Use the name in the code: "the config loader" becomes `loadConfig`.
- **Test.** Could the sentence sit unchanged in another project's docs? Then give the measure
  ("Search takes 80 ms, not 900 ms").
