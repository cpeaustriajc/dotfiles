# App UI rules

For dashboards, admin, settings and other dense screens. A row names the rule it breaks.

Follow Vercel's Web Interface Guidelines (https://vercel.com/design/guidelines), Jakub Krehel's
"Details that make interfaces feel better" (https://jakub.kr/writing/details-that-make-interfaces-feel-better),
Josh Comeau's "Designing Beautiful Shadows" (https://www.joshwcomeau.com/css/designing-shadows/) and
`Dammyjay93/interface-design` (https://github.com/Dammyjay93/interface-design). Take from them the
type, number, radius, shadow and image details.

Our choices:
- One 4- or 8-point grid; flag off-grid values such as 14px.
- One depth strategy per product, borders or shadows, not both on one surface.
- Density decided up front as a named control height (32px dense, 40px roomy), applied everywhere.
- Colour signals state; grey carries structure.
