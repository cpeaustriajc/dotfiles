# Layout and content rules

Step 3 of `SKILL.md`: check on every screen. A row names the rule it breaks.

- Drift from the design: spacing, radius, weight, colour, order, components the design lacks.
- Clutter: a description under every heading, helper text repeating the label. Recommend cutting.
- Truncated text with no way to read it in full (tooltip or title).
- Missing states: empty, loading, error, one item, very long values.
- A hand-built widget where the project's component library has one.
- Contradicting labels or calls to action ("Buy now" beside a different price flow).
