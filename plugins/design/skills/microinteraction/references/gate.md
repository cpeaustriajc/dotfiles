# The gate

Step 3 of `SKILL.md`. A candidate must pass all four questions, in order; record each answer.

1. **Frequency.** Use Emil Kowalski's frequency rule (https://emilkowal.ski/ui/great-animations):
   100+ a day or keyboard-initiated is rejected (Raycast has no open/close animation); tens a day
   only fast and subtle; occasional is eligible; rare or first-time holds the delight budget.
2. **Purpose.** Name one: feedback, spatial consistency, state indication, preventing a jarring
   change, explanation (marketing or onboarding only), delight (rare frequency only). No purpose,
   rejected.
3. **Speed.** UI motion under 300ms, per his duration bands. A moment that works only as a slow,
   showy animation fails.
4. **Function.** Decoration hinders functional, dense UI: data the user reads or acts on does not
   move for style (a mouse-tracking effect suits marketing, not a banking graph).
